# The-snake-by-LIVERslow
A classic implementation of the arcade game Snake, built using Python's built-in turtle module. Control the snake, collect food to grow longer, and avoid hitting the screen borders!

1. Features
    1.1 Graphical Interface:
      Built with Python's standard turtle graphics module.

    1.2. Smooth Controls:
       Responsive WASD key controls with built-in directional locks (e.g., cannot directly reverse into yourself).

    1.3. Growing Snake Mechanics:
       Consuming food dynamically appends new body segments to the snake.

    1.4.Randomized Food Spawning:
       Food appears at random locations on the grid after each collision.

    1.5. Border Collision Detection:
       The game detects when the player hits the screen boundaries and resets/ends the loop.

2. Game Controls
    W - Move Up

    S - Move Down

    A - Move Left

    D - Move Right

3. How to Run\
    Make sure you have Python installed on your system (turtle comes pre-installed with standard Python distributions). Run the script using your terminal or PyCharm.

4. How to Play\
    Launch the script to open the game window.\
    Press W, A, S, or D to start moving the green snake head.\
    Guide the snake head to touch the red food square.\
    Each piece of food grows your snake body and spawns a new piece of food.\
    Avoid touching the edges of the $800 \times 600$ window to keep playing!
